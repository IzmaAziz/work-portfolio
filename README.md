# Work Portfolio

A personal portfolio site built with React, Vite, and Tailwind CSS. Showcases projects, experience, certifications, and awards.

## Tech stack

- **React 19** + **TypeScript**
- **Vite** for build and dev server
- **Tailwind CSS** for styling
- **Framer Motion** for animations
- **shadcn/ui**-style components (Radix UI)

## Run locally

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
pnpm build          # Full app (client + server)
pnpm build:gh-pages # Static site for GitHub Pages
```

## Deploy (GitHub Pages)

The site is deployed automatically when you push to `main`. The **Deploy to GitHub Pages** workflow builds the static site and publishes it to GitHub Pages.

Live site: **https://izmaaziz.github.io/work-portfolio/**

See [DEPLOY.md](./DEPLOY.md) for first-time setup and troubleshooting.
